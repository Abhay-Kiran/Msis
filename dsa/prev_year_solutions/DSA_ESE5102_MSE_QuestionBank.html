Likely

What is an algorithm? List its characteristics. (2–3 marks)

An algorithm is a finite sequence of well-defined instructions that solves a problem. Characteristics (Horowitz–Sahni):

  • Input – zero or more quantities supplied externally.
  • Output – at least one quantity produced.
  • Definiteness – each step is clear and unambiguous.
  • Finiteness – terminates after a finite number of steps for all inputs.
  • Effectiveness – each step is basic enough to be carried out (e.g., with pencil and paper).
Likely

Define time complexity and space complexity. How is space complexity of a program computed?

Time complexity: amount of computer time an algorithm needs to run to completion, expressed as a function of input size n (counted in basic steps, not seconds).

Space complexity: amount of memory it needs. S(P) = c + SP(instance) where c is the fixed part (code, simple variables, constants) and SP is the variable part (arrays whose size depends on n, recursion stack).

Example: recursive sum of n elements uses a recursion stack of depth n+1 → S = O(n); iterative sum uses O(1).

/* Iterative sum: time O(n), extra space O(1) */
int sumIter(int a[], int n){
    int s = 0;                 /* 1 step                    */
    for(int i = 0; i < n; i++) /* loop test runs n+1 times  */
        s += a[i];             /* runs n times              */
    return s;                  /* 1 step  -> total 2n+3     */
}

/* Recursive sum: time O(n), space O(n) because of n+1 stack frames */
int sumRec(int a[], int n){
    if(n == 0) return 0;               /* base case             */
    return sumRec(a, n-1) + a[n-1];    /* T(n) = T(n-1) + c     */
}

1.3 Analysis of recursive programs & solving recurrences

Step 1 – write the recurrence from the code: (number of recursive calls) × T(size of each) + (work done outside the calls).

Step 2 – solve by substitution (iteration), recursion tree, or Master theorem.

Iteration (back-substitution) example: T(n) = T(n−1) + n, T(1)=1

T(n) = T(n−2) + (n−1) + n = T(n−3) + (n−2) + (n−1) + n = … = T(1) + 2 + 3 + … + n = n(n+1)/2 → O(n²). (Recursive selection sort, quicksort worst case.)

Example: T(n) = T(n/2) + c (binary search)

T(n) = T(n/4) + 2c = … = T(n/2ᵏ) + kc. Put n = 2ᵏ → k = log₂n → T(n) = T(1) + c·log₂n = O(log n).

Master theorem: T(n) = a·T(n/b) + f(n), a ≥ 1, b > 1

Compare f(n) with nlogba:

  • Case 1: f(n) = O(nlogba − ε) → T(n) = Θ(nlogba)
  • Case 2: f(n) = Θ(nlogba) → T(n) = Θ(nlogba · log n)
  • Case 3: f(n) = Ω(nlogba + ε) and a·f(n/b) ≤ k·f(n) for some k<1 → T(n) = Θ(f(n))

“General solution for a large class of recurrences” (Aho–Ullman): for T(n) = a·T(n/b) + d(n) with d(n) = nk: if a > bᵏ → O(nlogba); a = bᵏ → O(nᵏ log n); a < bᵏ → O(nᵏ). This is the same result in simpler form.

1.4 Randomized algorithms

An algorithm that makes random choices during execution; its running time or output can vary between runs on the same input.

  • Las Vegas – always gives the correct answer; running time is random (e.g. randomized quicksort: expected O(n log n) for every input).
  • Monte Carlo – fixed running time; answer correct with high probability (e.g. Miller–Rabin primality test).

Why randomize quicksort? Picking the pivot at random means no particular input (e.g. already-sorted) can force the O(n²) worst case; the bad case now only happens with tiny probability.

#include <stdlib.h>
/* Randomized partition: swap a random element into the pivot position,
   then use the normal Lomuto partition (see quicksort section). */
int randomizedPartition(int a[], int low, int high){
    int r = low + rand() % (high - low + 1);   /* random index in [low, high] */
    int t = a[r]; a[r] = a[high]; a[high] = t; /* move it to the end          */
    return partition(a, low, high);            /* pivot = a[high]             */
}

Key idea for O(1)

An operation is O(1) only if it never walks the list. In an SLL that is true for: insert at head, delete head, insert after a known node, insert at tail if a tail pointer is kept, and delete a given node (non-last) using the copy-next trick. Deleting the tail is O(n) because the new tail (the predecessor) can only be found by walking from the head.

  |                                             |
  v                                             v
[ 10 | *-]--> [ 20 | *-]--> [ 30 | *-]--> [ 40 | NULL ]

#include <stdio.h>
#include <stdlib.h>

/* ---------- Data structure design ---------- */
/* One node = data field + link to the next node */
typedef struct Node {
    int data;
    struct Node *next;
} Node;

/* The list keeps head AND tail so both ends can be reached in O(1).
   size is maintained so length() is O(1) as well.                    */
typedef struct {
    Node *head;
    Node *tail;
    int   size;
} SList;

void initList(SList *L){
    L->head = L->tail = NULL;   /* empty list: both pointers NULL */
    L->size = 0;
}

/* Allocate a node and fill it. Exits if malloc fails. */
Node *createNode(int x){
    Node *n = (Node *)malloc(sizeof(Node));
    if(n == NULL){ printf("Memory allocation failed\n"); exit(1); }
    n->data = x;
    n->next = NULL;
    return n;
}

/* ---------- INSERT AT FRONT : O(1) ---------- */
void insertFront(SList *L, int x){
    Node *n = createNode(x);
    n->next = L->head;          /* new node points to old first node   */
    L->head = n;                /* head now points to new node          */
    if(L->tail == NULL)         /* list was empty -> new node is also tail */
        L->tail = n;
    L->size++;
}

/* ---------- INSERT AT REAR : O(1) (only because tail is kept) ---------- */
void insertRear(SList *L, int x){
    Node *n = createNode(x);
    if(L->tail == NULL){        /* empty list */
        L->head = L->tail = n;
    } else {
        L->tail->next = n;      /* link old last node to new node */
        L->tail = n;            /* new node becomes the tail       */
    }
    L->size++;
}

/* ---------- INSERT AFTER A GIVEN NODE p : O(1) ---------- */
void insertAfter(SList *L, Node *p, int x){
    if(p == NULL) return;
    Node *n = createNode(x);
    n->next = p->next;          /* new node takes over p's successor */
    p->next = n;                /* p now points to new node          */
    if(p == L->tail)            /* inserted after last node          */
        L->tail = n;
    L->size++;
}

/* ---------- DELETE FROM FRONT : O(1) ----------
   Returns 1 on success and puts the removed value in *out, 0 if empty. */
int deleteFront(SList *L, int *out){
    if(L->head == NULL){ printf("List empty\n"); return 0; }
    Node *temp = L->head;       /* remember node to free           */
    *out = temp->data;
    L->head = temp->next;       /* second node becomes first       */
    if(L->head == NULL)         /* list became empty               */
        L->tail = NULL;
    free(temp);
    L->size--;
    return 1;
}

/* ---------- DELETE A GIVEN NODE p (p is not the last node) : O(1) ----------
   Trick: we cannot reach p's predecessor, so copy the NEXT node's data
   into p and delete the next node instead.                             */
int deleteGivenNode(SList *L, Node *p){
    if(p == NULL || p->next == NULL){
        printf("Cannot delete last node in O(1)\n");
        return 0;
    }
    Node *q = p->next;          /* node that will be physically removed */
    p->data = q->data;          /* copy successor's data into p         */
    p->next = q->next;          /* bypass q                             */
    if(q == L->tail)            /* if q was tail, p is the new tail     */
        L->tail = p;
    free(q);
    L->size--;
    return 1;
}

/* ---------- DELETE AFTER A GIVEN NODE p : O(1) ---------- */
int deleteAfter(SList *L, Node *p, int *out){
    if(p == NULL || p->next == NULL) return 0;
    Node *q = p->next;
    *out = q->data;
    p->next = q->next;
    if(q == L->tail) L->tail = p;
    free(q);
    L->size--;
    return 1;
}

/* ---------- DELETE FROM REAR : O(n)  (needs the predecessor of tail) ---------- */
int deleteRear(SList *L, int *out){
    if(L->head == NULL) return 0;
    if(L->head == L->tail){                 /* single node */
        *out = L->head->data;
        free(L->head);
        L->head = L->tail = NULL;
    } else {
        Node *prev = L->head;
        while(prev->next != L->tail)         /* walk to second-last node */
            prev = prev->next;
        *out = L->tail->data;
        free(L->tail);
        prev->next = NULL;
        L->tail = prev;
    }
    L->size--;
    return 1;
}

/* ---------- DELETE BY KEY : O(n) ---------- */
int deleteKey(SList *L, int key){
    Node *prev = NULL, *cur = L->head;
    while(cur != NULL && cur->data != key){ /* search, remembering prev */
        prev = cur;
        cur  = cur->next;
    }
    if(cur == NULL) return 0;                 /* key not found            */
    if(prev == NULL) L->head = cur->next;     /* deleting first node      */
    else             prev->next = cur->next;  /* bypass cur               */
    if(cur == L->tail) L->tail = prev;        /* deleting last node       */
    free(cur);
    L->size--;
    return 1;
}

/* ---------- INSERT AT POSITION pos (0-based) : O(pos) ---------- */
void insertAt(SList *L, int pos, int x){
    if(pos <= 0){ insertFront(L, x); return; }
    if(pos >= L->size){ insertRear(L, x); return; }
    Node *p = L->head;
    for(int i = 0; i < pos - 1; i++)  /* stop at node before the position */
        p = p->next;
    insertAfter(L, p, x);
}

/* ---------- SEARCH : O(n) ---------- */
Node *search(SList *L, int key){
    for(Node *p = L->head; p != NULL; p = p->next)
        if(p->data == key) return p;
    return NULL;
}

/* ---------- REVERSE (in place) : O(n) time, O(1) space ---------- */
void reverse(SList *L){
    Node *prev = NULL, *cur = L->head, *nxt;
    L->tail = L->head;            /* old head becomes the tail */
    while(cur != NULL){
        nxt = cur->next;          /* save rest of list          */
        cur->next = prev;         /* reverse this link          */
        prev = cur;               /* move prev forward          */
        cur = nxt;                /* move cur forward           */
    }
    L->head = prev;               /* last node is the new head  */
}

/* ---------- MIDDLE NODE : slow/fast pointers, O(n) ---------- */
Node *middle(SList *L){
    Node *slow = L->head, *fast = L->head;
    while(fast != NULL && fast->next != NULL){
        slow = slow->next;        /* 1 step  */
        fast = fast->next->next;  /* 2 steps */
    }
    return slow;
}

void display(SList *L){
    for(Node *p = L->head; p != NULL; p = p->next)
        printf("%d -> ", p->data);
    printf("NULL\n");
}

int main(void){
    SList L; int v;
    initList(&L);
    insertFront(&L, 20);         /* 20                 */
    insertFront(&L, 10);         /* 10 20              */
    insertRear(&L, 40);          /* 10 20 40           */
    insertAfter(&L, search(&L, 20), 30); /* 10 20 30 40 */
    display(&L);
    deleteFront(&L, &v);         /* removes 10         */
    deleteGivenNode(&L, search(&L, 30)); /* 20 40       */
    display(&L);
    reverse(&L);                 /* 40 20              */
    display(&L);
    return 0;
}

Variation

SLL with a header (dummy) node — why use it?

A header node is an extra node at the front that holds no data. The list is empty when header->next == NULL. Because every real node now has a predecessor, insert/delete at the front need no special case — the same “insert after p / delete after p” code works everywhere. This is the style used in Aho–Hopcroft–Ullman (your reference 2), where a position is represented by a pointer to the previous cell.

/* With a header node, deleting the element at "position" p
   (p points to the cell BEFORE the one being deleted) is always O(1). */
void deleteAtPosition(Node *p){
    Node *q = p->next;       /* cell to delete      */
    p->next = q->next;       /* unlink it           */
    free(q);
}
void insertAtPosition(Node *p, int x){   /* insert after p */
    Node *n = createNode(x);
    n->next = p->next;
    p->next = n;
}
Variation

Detect a loop (cycle) in a singly linked list. Extra

/* Floyd's tortoise and hare: if a cycle exists, fast eventually meets slow.
   Time O(n), space O(1). */
int hasCycle(Node *head){
    Node *slow = head, *fast = head;
    while(fast != NULL && fast->next != NULL){
        slow = slow->next;
        fast = fast->next->next;
        if(slow == fast) return 1;   /* pointers met -> cycle */
    }
    return 0;                        /* fast reached NULL -> no cycle */
}

3. Doubly linked & circular lists (L8)

Variation

Design a DLL. Write functions to insert at front/rear and delete a given node in O(1). Why is delete-last O(1) in a DLL but O(n) in an SLL?

Each DLL node has a prev link, so the predecessor of any node (including the tail) is available in O(1). That is exactly what an SLL lacks.

NULL <-[prev|10|next]<=>[prev|20|next]<=>[prev|30|next]-> NULL
         ^head                                   ^tail

typedef struct DNode {
    int data;
    struct DNode *prev, *next;
} DNode;

typedef struct { DNode *head, *tail; } DList;

DNode *newDNode(int x){
    DNode *n = (DNode *)malloc(sizeof(DNode));
    n->data = x; n->prev = n->next = NULL;
    return n;
}

/* O(1) */
void dInsertFront(DList *L, int x){
    DNode *n = newDNode(x);
    n->next = L->head;
    if(L->head) L->head->prev = n;   /* old head points back to n */
    else        L->tail = n;         /* list was empty            */
    L->head = n;
}

/* O(1) */
void dInsertRear(DList *L, int x){
    DNode *n = newDNode(x);
    n->prev = L->tail;
    if(L->tail) L->tail->next = n;
    else        L->head = n;
    L->tail = n;
}

/* O(1): delete ANY node p, including first and last */
void dDeleteNode(DList *L, DNode *p){
    if(p->prev) p->prev->next = p->next;  /* bypass p going forward  */
    else        L->head = p->next;        /* p was head              */
    if(p->next) p->next->prev = p->prev;  /* bypass p going backward */
    else        L->tail = p->prev;        /* p was tail              */
    free(p);
}

/* O(1) delete last — possible because tail->prev is known */
void dDeleteRear(DList *L){
    if(L->tail) dDeleteNode(L, L->tail);
}
Variation

Circular singly linked list: insert at front and rear in O(1) using only a last pointer.

In a circular list the last node points back to the first. Keeping only last gives both ends in O(1): first = last->next.

/* last points to the last node; last->next is the first node */
Node *cInsertFront(Node *last, int x){
    Node *n = createNode(x);
    if(last == NULL){ n->next = n; return n; }  /* single node points to itself */
    n->next = last->next;     /* new node points to old first */
    last->next = n;           /* last now points to new first */
    return last;
}
Node *cInsertRear(Node *last, int x){
    last = cInsertFront(last, x);  /* insert at front ...          */
    return last->next;             /* ... then make it the new last */
}

4.1 Array-based stack

index:   0    1    2    3    4   ...  MAX-1
       [ 5 ][ 8 ][ 3 ][   ][   ] ...
                    ^ top = 2      (top = -1 means empty, top = MAX-1 means full)

#include <stdio.h>
#define MAX 100

/* ---------- Data structure ---------- */
typedef struct {
    int items[MAX];   /* storage for elements                 */
    int top;          /* index of top element; -1 when empty  */
} Stack;

void initStack(Stack *s){ s->top = -1; }

int isEmpty(Stack *s){ return s->top == -1; }
int isFull (Stack *s){ return s->top == MAX - 1; }

/* ---------- PUSH : O(1) ---------- */
void push(Stack *s, int x){
    if(isFull(s)){                 /* no room -> overflow */
        printf("Stack Overflow\n");
        return;
    }
    s->top++;                      /* move top up first   */
    s->items[s->top] = x;          /* then store element  */
}

/* ---------- POP : O(1) ----------
   Returns 1 and stores the popped value in *x; returns 0 on underflow. */
int pop(Stack *s, int *x){
    if(isEmpty(s)){                /* nothing to remove   */
        printf("Stack Underflow\n");
        return 0;
    }
    *x = s->items[s->top];         /* read top element    */
    s->top--;                      /* then move top down  */
    return 1;
}

/* ---------- PEEK : O(1) ---------- */
int peek(Stack *s, int *x){
    if(isEmpty(s)) return 0;
    *x = s->items[s->top];         /* read without removing */
    return 1;
}

void displayStack(Stack *s){
    for(int i = s->top; i >= 0; i--)   /* print from top to bottom */
        printf("%d\n", s->items[i]);
}

int main(void){
    Stack s; int v;
    initStack(&s);

   except when malloc fails (heap exhausted). ---------- */
void lpush(LStack *s, int x){
    SNode *n = (SNode *)malloc(sizeof(SNode));
    if(n == NULL){ printf("Overflow: heap full\n"); return; }
    n->data = x;
    n->next = s->top;     /* new node points to current top */
    s->top  = n;          /* new node becomes top           */
    s->count++;
}

/* ---------- POP (delete one element) : delete at head, O(1) ---------- */
int lpop(LStack *s, int *x){
    if(s->top == NULL){               /* empty -> underflow             */
        printf("Stack Underflow\n");
        return 0;
    }
    SNode *temp = s->top;             /* node to delete                  */
    *x = temp->data;                  /* save its value                  */
    s->top = temp->next;              /* top moves to next node          */
    free(temp);                       /* release memory (important!)     */
    s->count--;
    return 1;
}

/* ---------- DELETE ALL ELEMENTS : O(n) ---------- */
void deleteAll(LStack *s){
    int x;
    while(s->top != NULL)             /* pop until empty, freeing each node */
        lpop(s, &x);
}

void popK(LStack *s, int k){

}

void infixToPostfix(const char *in, char *out){
    char st[100]; int top = -1, k = 0;
    for(int i = 0; in[i]; i++){
        char c = in[i];
        if(c == ' ') continue;
        if(isalnum(c))             out[k++] = c;           /* operand            */
        else if(c == '(')          st[++top] = c;          /* push '('           */
        else if(c == ')'){                                  /* pop until '('      */

                  (prec(st[top]) > prec(c) ||
                   (prec(st[top]) == prec(c) && c != '^')))
                out[k++] = st[top--];
            st[++top] = c;
        }
    }
    while(top >= 0) out[k++] = st[top--];                   /* flush stack        */
    out[k] = '\0';

#include <stdio.h>
#include <stdlib.h>

/* ---------- Data structure ---------- */
typedef struct QNode {
    int data;
    struct QNode *next;
} QNode;

typedef struct {
    QNode *front;   /* first node: deletions happen here  */
    QNode *rear;    /* last node : insertions happen here */
} Queue;

void initQueue(Queue *q){ q->front = q->rear = NULL; }
int  isQEmpty(Queue *q){ return q->front == NULL; }

/* ---------- ENQUEUE : insert at rear, O(1) ---------- */
void enqueue(Queue *q, int x){
    QNode *n = (QNode *)malloc(sizeof(QNode));
    if(n == NULL){ printf("Queue overflow (no memory)\n"); return; }
    n->data = x;
    n->next = NULL;               /* new node will be the last node   */
    if(q->rear == NULL){          /* queue empty: node is front AND rear */
        q->front = q->rear = n;
        return;
    }
    q->rear->next = n;            /* link old rear to new node        */
    q->rear = n;                  /* update rear                      */
}

/* ---------- DEQUEUE : delete at front, O(1) ---------- */
int dequeue(Queue *q, int *x){
    if(isQEmpty(q)){
        printf("Queue underflow\n");
        return 0;
    }
    QNode *temp = q->front;       /* node to remove                  */
    *x = temp->data;
    q->front = temp->next;        /* advance front                   */
    if(q->front == NULL)          /* queue became empty ->           */
        q->rear = NULL;           /* rear must also be reset (bug if missed!) */
    free(temp);
    return 1;
}

int frontElem(Queue *q, int *x){
    if(isQEmpty(q)) return 0;
    *x = q->front->data;
    return 1;
}

void displayQ(Queue *q){
    for(QNode *p = q->front; p; p = p->next) printf("%d ", p->data);
    printf("\n");
}

int main(void){
    Queue q; int v;
    initQueue(&q);
    enqueue(&q, 10); enqueue(&q, 20); enqueue(&q, 30);
    dequeue(&q, &v);              /* v = 10 (first in, first out) */
    displayQ(&q);                 /* 20 30                        */
    return 0;
}

Why insert at the tail and delete at the head? In an SLL, deleting at the tail is O(n). Deleting at the head and inserting at the tail are both O(1), so the front must be the head.

Aho–Ullman version (reference 2) uses a header cell: front always points to a dummy header, so the queue is empty when front == rear. Dequeue removes front->next. Either version is acceptable; mention whichever your lecturer used.

5.3 Circular queue (L12)

#define CQMAX 5
typedef struct {
    int a[CQMAX];
    int front;      /* index of first element           */
    int rear;       /* index of last element            */
    int count;      /* number of elements (makes full/empty easy) */

void initCQ(CQueue *q){ q->front = 0; q->rear = -1; q->count = 0; }

int cqFull (CQueue *q){ return q->count == CQMAX; }
int cqEmpty(CQueue *q){ return q->count == 0; }

/* rear wraps around using modulo -> freed slots at the start are reused */
void cqEnqueue(CQueue *q, int x){
    if(cqFull(q)){ printf("Circular queue full\n"); return; }
    q->rear = (q->rear + 1) % CQMAX;
    q->a[q->rear] = x;
    q->count++;
}

int cqDequeue(CQueue *q, int *x){
    if(cqEmpty(q)){ printf("Circular queue empty\n"); return 0; }
    *x = q->a[q->front];
    q->front = (q->front + 1) % CQMAX;   /* front also wraps around */
    q->count--;
    return 1;
}

void displayCQ(CQueue *q){
    for(int i = 0, j = q->front; i < q->count; i++, j = (j + 1) % CQMAX)
        printf("%d ", q->a[j]);
    printf("\n");
}

#define HMAX 100
typedef struct { int h[HMAX + 1]; int size; } MinHeap;   /* h[1..size] used */

void initHeap(MinHeap *H){ H->size = 0; }

/* INSERT: put at the end, then "percolate up" while smaller than parent. O(log n) */
void heapInsert(MinHeap *H, int x){
    if(H->size == HMAX){ printf("Heap full\n"); return; }
    int i = ++H->size;                       /* new hole at the end   */
    while(i > 1 && H->h[i/2] > x){           /* parent bigger?        */
        H->h[i] = H->h[i/2];                 /* move parent down      */
        i /= 2;                              /* hole moves up         */
    }
    H->h[i] = x;                             /* place x in the hole   */
}

/* DELETEMIN: remove root, move last element to root, "percolate down". O(log n) */
int heapDeleteMin(MinHeap *H, int *min){
    if(H->size == 0){ printf("Heap empty\n"); return 0; }
    *min = H->h[1];                          /* smallest is at the root */
    int last = H->h[H->size--];              /* element to re-insert    */
    int i = 1, child;
    while(2 * i <= H->size){                 /* while i has a child     */
        child = 2 * i;
        if(child + 1 <= H->size && H->h[child + 1] < H->h[child])
            child++;                         /* pick the smaller child  */
        if(H->h[child] < last){
            H->h[i] = H->h[child];           /* move child up           */
            i = child;
        } else break;
    }
    H->h[i] = last;
    return 1;
}

Answer: Insertion sort (bubble sort with a swap flag is also accepted). On already-sorted input the inner loop never runs, so only n−1 comparisons are made → O(n). On reverse-sorted input element i is shifted i times → 1+2+…+(n−1) = n(n−1)/2 → O(n²).

/* INSERTION SORT
   Idea: a[0..i-1] is already sorted. Take key = a[i] and shift every
   larger element of the sorted part one place right, then drop key
   into the gap.                                                      */
void insertionSort(int a[], int n){
    for(int i = 1; i < n; i++){
        int key = a[i];          /* element to be inserted            */
        int j = i - 1;
        /* shift elements greater than key one position to the right */
        while(j >= 0 && a[j] > key){
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;          /* insert key in its correct place   */
    }
}
/* Best  (already sorted): while-test fails immediately -> n-1 comparisons -> O(n)
   Worst (reverse sorted): i shifts for each i        -> n(n-1)/2         -> O(n^2)
   Average: about n^2/4 -> O(n^2). Stable: yes. In-place: yes (O(1) extra). */

/* BUBBLE SORT with early exit
   Each pass bubbles the largest remaining element to the end.
   If a whole pass makes no swap, the array is sorted -> stop.        */
void bubbleSort(int a[], int n){
    for(int pass = 0; pass < n - 1; pass++){
        int swapped = 0;                       /* flag for this pass   */
        for(int j = 0; j < n - 1 - pass; j++){ /* last 'pass' items already in place */
            if(a[j] > a[j + 1]){
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = 1;
            }
        }
        if(!swapped) break;    /* sorted input: one pass of n-1 comparisons -> O(n) */
    }
}

/* SELECTION SORT — for contrast: always O(n^2), even on sorted input,
   because finding the minimum always scans the whole unsorted part.   */
void selectionSort(int a[], int n){
    for(int i = 0; i < n - 1; i++){
        int min = i;
        for(int j = i + 1; j < n; j++)        /* find smallest in a[i..n-1] */
            if(a[j] < a[min]) min = j;
        int t = a[i]; a[i] = a[min]; a[min] = t;  /* at most n-1 swaps total */
    }
}

#include <stdio.h>

/* MERGE: combine sorted a[low..mid] and a[mid+1..high] into one sorted run.
   Uses a temporary array -> O(n) extra space. Time O(high-low+1).       */
void merge(int a[], int low, int mid, int high){
    int temp[high - low + 1];
    int i = low;        /* index into left half   */
    int j = mid + 1;    /* index into right half  */
    int k = 0;          /* index into temp        */

    while(i <= mid && j <= high){        /* pick the smaller front element    */
        if(a[i] <= a[j]) temp[k++] = a[i++]; /* '<=' keeps equal keys in order -> stable */
        else             temp[k++] = a[j++];
    }
    while(i <= mid)  temp[k++] = a[i++];  /* copy leftovers of left half  */
    while(j <= high) temp[k++] = a[j++];  /* copy leftovers of right half */

    for(k = 0, i = low; i <= high; i++, k++)   /* copy back into a[] */
        a[i] = temp[k];
}

/* MERGE SORT: divide into halves, sort each recursively, then merge. */
void mergeSort(int a[], int low, int high){
    if(low < high){                     /* 0 or 1 element: already sorted */
        int mid = (low + high) / 2;     /* DIVIDE                         */
        mergeSort(a, low, mid);         /* CONQUER left half              */
        mergeSort(a, mid + 1, high);    /* CONQUER right half             */
        merge(a, low, mid, high);       /* COMBINE                        */
    }
}

    mergeSort(a, 0, n - 1);

    return 0;
}

Derivation of time complexity

Dividing takes O(1); two recursive calls on n/2 elements; merging n elements takes at most n−1 comparisons, i.e. cn. So

T(n) = 2T(n/2) + cn, T(1) = c

Substitution:

T(n) = 2[2T(n/4) + cn/2] + cn = 4T(n/4) + 2cn
= 8T(n/8) + 3cn
= 2ᵏ T(n/2ᵏ) + k·cn
Let n = 2ᵏ ⇒ k = log₂n:
T(n) = n·T(1) + cn·log₂n = cn + cn·log₂n = O(n log n)

Recursion tree: level 0 costs cn; level 1 has 2 nodes of cn/2 = cn; every level costs cn; there are log₂n + 1 levels → cn(log₂n + 1) = O(n log n).

Master theorem: a = 2, b = 2, f(n) = n, nlog₂2 = n = f(n) → Case 2 → Θ(n log n).

6.3 Quick sort (L13)

void swap(int *x, int *y){ int t = *x; *x = *y; *y = t; }

/* LOMUTO PARTITION: pivot = last element.
   After the loop, a[low..i] <= pivot and a[i+1..high-1] > pivot.
   The pivot is then placed at i+1, its final sorted position.     */
int partition(int a[], int low, int high){
    int pivot = a[high];
    int i = low - 1;                    /* end of the "<= pivot" region */
    for(int j = low; j < high; j++){
        if(a[j] <= pivot){
            i++;
            swap(&a[i], &a[j]);         /* grow the "<= pivot" region */
        }
    }
    swap(&a[i + 1], &a[high]);          /* put pivot in place          */
    return i + 1;
}

void quickSort(int a[], int low, int high){
    if(low < high){
        int p = partition(a, low, high);   /* pivot now at index p      */
        quickSort(a, low, p - 1);          /* sort elements before pivot */
        quickSort(a, p + 1, high);         /* sort elements after pivot  */
    }
}

6.4 Heap sort (L14)

/* Sift a[i] down in a MAX-heap of size n (0-based: children 2i+1, 2i+2). */
void heapify(int a[], int n, int i){
    int largest = i, l = 2*i + 1, r = 2*i + 2;
    if(l < n && a[l] > a[largest]) largest = l;
    if(r < n && a[r] > a[largest]) largest = r;
    if(largest != i){
        swap(&a[i], &a[largest]);   /* move larger child up         */
        heapify(a, n, largest);     /* continue sifting down        */
    }
}

void heapSort(int a[], int n){
    for(int i = n/2 - 1; i >= 0; i--)   /* 1. build max-heap: O(n)          */
        heapify(a, n, i);
    for(int i = n - 1; i > 0; i--){     /* 2. repeatedly remove the max     */
        swap(&a[0], &a[i]);             /*    max goes to its final place   */
        heapify(a, i, 0);               /*    restore heap on a[0..i-1]     */
    }
}
/* Time O(n log n) in all cases, O(1) extra space, not stable. */

/* LINEAR SEARCH: works on unsorted data. Best O(1), worst/avg O(n). */
int linearSearch(int a[], int n, int key){
    for(int i = 0; i < n; i++)
        if(a[i] == key) return i;   /* found: return index */
    return -1;                      /* not found           */
}

/* BINARY SEARCH (iterative): array must be SORTED.
   Each comparison halves the search interval -> O(log n). */
int binarySearch(int a[], int n, int key){
    int low = 0, high = n - 1;
    while(low <= high){
        int mid = low + (high - low) / 2;   /* avoids int overflow of (low+high) */
        if(a[mid] == key) return mid;
        else if(a[mid] < key) low = mid + 1;  /* key is in right half */
        else                  high = mid - 1; /* key is in left half  */
    }
    return -1;
}

/* BINARY SEARCH (recursive): T(n) = T(n/2) + c = O(log n), stack O(log n) */
int binarySearchRec(int a[], int low, int high, int key){
    if(low > high) return -1;                       /* empty interval */
    int mid = low + (high - low) / 2;
    if(a[mid] == key) return mid;
    if(a[mid] < key) return binarySearchRec(a, mid + 1, high, key);
    return binarySearchRec(a, low, mid - 1, key);
}

Fibonacci search (L18)

Works on a sorted array like binary search, but splits the range using consecutive Fibonacci numbers instead of halves. It needs only addition/subtraction to compute the split point (no division), which was historically an advantage and can still matter on small processors without hardware divide. Complexity O(log n).

Idea: find the smallest Fibonacci number Fm ≥ n. Compare key with element at offset + Fm−2. If key is larger, drop the front Fm−2 part (move down one Fibonacci number); if smaller, keep only the front part (move down two).

int fibonacciSearch(int a[], int n, int key){
    int f2 = 0, f1 = 1, f = f1 + f2;   /* F(m-2), F(m-1), F(m)            */
    while(f < n){                      /* smallest Fibonacci number >= n  */
        f2 = f1; f1 = f; f = f1 + f2;
    }
    int offset = -1;                   /* elements up to offset are eliminated */
    while(f > 1){
        int i = (offset + f2 < n - 1) ? offset + f2 : n - 1;  /* probe index */
        if(a[i] < key){                /* key is after i: shift window by F(m-2) */
            f = f1; f1 = f2; f2 = f - f1;
            offset = i;
        } else if(a[i] > key){         /* key is before i: shrink by two steps   */
            f = f2; f1 = f1 - f2; f2 = f - f1;
        } else return i;               /* found */
    }
    if(f1 && offset + 1 < n && a[offset + 1] == key)  /* one element left */
        return offset + 1;
    return -1;
}

Properties of a BST

  1. It is a binary tree: each node has at most two children.
  2. Every key in the left subtree of a node is less than the node's key.
  3. Every key in the right subtree is greater than the node's key.
  4. Both left and right subtrees are themselves BSTs.
  5. No duplicate keys (usual convention).
  6. Inorder traversal visits keys in ascending order.
  7. Minimum is the leftmost node; maximum is the rightmost node.
  8. Search/insert/delete take O(h) where h = height: O(log n) if balanced, O(n) if skewed.

8.3 BST code

#include <stdio.h>
#include <stdlib.h>

/* ---------- Data structure ---------- */
typedef struct TreeNode {
    int key;
    struct TreeNode *left;    /* subtree with smaller keys */
    struct TreeNode *right;   /* subtree with larger keys  */
} TreeNode;

TreeNode *newTreeNode(int key){
    TreeNode *n = (TreeNode *)malloc(sizeof(TreeNode));
    n->key = key;
    n->left = n->right = NULL;   /* new node is always a leaf */
    return n;
}

/* ---------- INSERT (recursive) : O(h) ----------
   Go left if key is smaller, right if larger; attach at the NULL found. */
TreeNode *insert(TreeNode *root, int key){
    if(root == NULL)                       /* empty spot found        */
        return newTreeNode(key);
    if(key < root->key)
        root->left = insert(root->left, key);
    else if(key > root->key)
        root->right = insert(root->right, key);
    /* key == root->key : duplicate, ignore */
    return root;                           /* root pointer unchanged  */
}

/* ---------- INSERT (iterative) : O(h), no recursion stack ---------- */
TreeNode *insertIter(TreeNode *root, int key){
    TreeNode *n = newTreeNode(key);
    if(root == NULL) return n;
    TreeNode *cur = root, *parent = NULL;
    while(cur != NULL){                    /* walk down to a NULL link */
        parent = cur;
        if(key < cur->key)      cur = cur->left;
        else if(key > cur->key) cur = cur->right;
        else { free(n); return root; }     /* duplicate */
    }
    if(key < parent->key) parent->left = n;   /* attach to parent */
    else                  parent->right = n;
    return root;
}

/* ---------- SEARCH : O(h) ---------- */
TreeNode *search(TreeNode *root, int key){
    while(root != NULL && root->key != key)
        root = (key < root->key) ? root->left : root->right;
    return root;                           /* NULL if not found */
}

/* ---------- MIN / MAX ---------- */
TreeNode *findMin(TreeNode *root){
    while(root && root->left) root = root->left;    /* leftmost  */
    return root;
}
TreeNode *findMax(TreeNode *root){
    while(root && root->right) root = root->right;  /* rightmost */
    return root;
}

/* ---------- DELETE : O(h), handles all three cases ---------- */
TreeNode *deleteNode(TreeNode *root, int key){
    if(root == NULL) return NULL;                     /* key not present */
    if(key < root->key)
        root->left = deleteNode(root->left, key);
    else if(key > root->key)
        root->right = deleteNode(root->right, key);
    else {                                            /* found the node  */
        if(root->left == NULL){                       /* case 1 & 2: 0 or 1 child */
            TreeNode *r = root->right;
            free(root);
            return r;                                 /* child (or NULL) replaces it */
        }
        if(root->right == NULL){
            TreeNode *l = root->left;
            free(root);
            return l;
        }
        /* case 3: two children -> copy inorder successor, delete it from right subtree */
        TreeNode *succ = findMin(root->right);
        root->key = succ->key;
        root->right = deleteNode(root->right, succ->key);
    }
    return root;
}

/* ---------- TRAVERSALS : each O(n) ---------- */
void inorder(TreeNode *r){            /* Left, Root, Right -> sorted order */
    if(r){ inorder(r->left); printf("%d ", r->key); inorder(r->right); }
}
void preorder(TreeNode *r){           /* Root, Left, Right */
    if(r){ printf("%d ", r->key); preorder(r->left); preorder(r->right); }
}
void postorder(TreeNode *r){          /* Left, Right, Root */
    if(r){ postorder(r->left); postorder(r->right); printf("%d ", r->key); }
}

/* Level order uses a QUEUE (array-based here for brevity) */
void levelOrder(TreeNode *root){
    TreeNode *q[100]; int front = 0, rear = 0;
    if(root) q[rear++] = root;
    while(front < rear){
        TreeNode *t = q[front++];             /* dequeue          */
        printf("%d ", t->key);
        if(t->left)  q[rear++] = t->left;     /* enqueue children */
        if(t->right) q[rear++] = t->right;
    }
}

/* ---------- HEIGHT, COUNT, LEAVES ---------- */
int height(TreeNode *r){              /* edges on longest path; empty tree = -1 */
    if(r == NULL) return -1;
    int lh = height(r->left), rh = height(r->right);
    return 1 + (lh > rh ? lh : rh);
}
int countNodes(TreeNode *r){ return r ? 1 + countNodes(r->left) + countNodes(r->right) : 0; }
int countLeaves(TreeNode *r){
    if(r == NULL) return 0;
    if(!r->left && !r->right) return 1;
    return countLeaves(r->left) + countLeaves(r->right);
}

Preorder's first element A is the root. In inorder, left of A = {D, B, E}, right = {F, C, G}. Next in preorder is B → root of left part; in inorder D is left of B and E right. Next C → root of right part; F left, G right.

Note: preorder + postorder alone does not uniquely determine a general binary tree; inorder is required with either of them. For a BST, preorder alone is enough (just insert the keys in that order).

Variation

Insert 10, 20, 30, 40, 50 into an empty BST. What happens, and what is the search complexity?

Each key is larger than all previous ones, so each goes to the right — the tree degenerates into a right-skewed “linked list” of height 4. Search becomes O(n). This is why balanced trees (AVL, red-black — L23) are used: they keep height O(log n) by rotations.

Tree terminology (2-mark questions)

  • Root – node with no parent. Leaf – node with no children. Internal node – has at least one child.
  • Degree of a node – number of children. Siblings – nodes with the same parent.
  • Depth / level of a node – number of edges from the root (root at level 0). Height of tree – max depth.
  • Full (strict) binary tree – every node has 0 or 2 children. Complete binary tree – all levels full except possibly the last, which is filled left to right (used by heaps). Perfect – all levels completely full.
  • Maximum nodes in a binary tree of height h: 2h+1 − 1. Minimum height with n nodes: ⌈log₂(n+1)⌉ − 1.
