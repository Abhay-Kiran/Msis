L1–L6 · Algorithm specification, performance, recurrences, randomized algorithms

Analysis and recursion

  • Count the dominant operation, then keep the highest-order term: two nested loops to n give Θ(n²); a loop that halves i gives Θ(lg n).
  • Master theorem for T(n) = aT(n/b) + f(n): compare f(n) with nlog_b a. Smaller → Θ(nlog_b a). Equal → multiply by lg n. Larger (and regular) → Θ(f(n)).
  • Subtract-type recurrences like T(n) = T(n−1) + n are not master-theorem cases; unroll them as a sum.
  • Randomized algorithms make the expected running time independent of the input order, which is why randomized quick sort has no "bad input".

Recursive insertion sort, and do two elements sum to x CLRS 2.3-4, 2.3-7

Recursive insertion sort sorts the first n−1 elements, then inserts the last one, giving T(n) = T(n−1) + Θ(n) = Θ(n²). For the two-sum test, sort first and then walk two pointers inward: if the sum is too small move the left pointer right, if too big move the right pointer left.

recursion.c
#include <stdio.h>

/* CLRS 2.3-4: recursive insertion sort.
   Sort a[0..n-2] recursively, then insert a[n-1].  T(n) = T(n-1) + Θ(n) = Θ(n²) */
void insertionSortRec(int a[], int n) {
    int key, j;
    if (n <= 1) return;
    insertionSortRec(a, n - 1);
    key = a[n - 1];
    j = n - 2;
    while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
    a[j + 1] = key;
}

/* CLRS 2.3-7: do two elements sum to x? Sort first (Θ(n lg n) with merge sort),
   then two pointers from both ends in Θ(n). */
int twoSum(int a[], int n, int x, int *p, int *q) {
    int i = 0, j = n - 1;
    while (i < j) {
        if (a[i] + a[j] == x) { *p = a[i]; *q = a[j]; return 1; }
        if (a[i] + a[j] < x) i++; else j--;
    }
    return 0;
}

int main(void) {
    int a[100], n, i, x, p, q;
    printf("n: "); scanf("%d", &n);
    printf("Elements: ");
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    printf("Target sum x: "); scanf("%d", &x);
    insertionSortRec(a, n);
    printf("\nSorted: ");
    for (i = 0; i < n; i++) printf("%d ", a[i]);
    if (twoSum(a, n, x, &p, &q)) printf("\nYes: %d + %d = %d\n", p, q, x);
    else printf("\nNo two elements sum to %d\n", x);
    return 0;
}

Random permutation of an array CLRS 5.3

At step i, swap a[i] with a random element from a[i..n−1]. Picking from the whole array each time (a common mistake) does not give equally likely permutations.

randperm.c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

/* CLRS 5.3 RANDOMIZE-IN-PLACE (Fisher-Yates): every permutation equally likely, O(n) */
void randomizeInPlace(int a[], int n) {
    int i, j, t;
    for (i = 0; i < n; i++) {
        j = i + rand() % (n - i);     /* random index in a[i..n-1] */
        t = a[i]; a[i] = a[j]; a[j] = t;
    }
}

int main(void) {
    int a[100], n, i, run;
    srand(time(NULL));
    printf("n: "); scanf("%d", &n);
    for (i = 0; i < n; i++) a[i] = i + 1;
    for (run = 1; run <= 3; run++) {
        randomizeInPlace(a, n);
        printf("Shuffle %d: ", run);
        for (i = 0; i < n; i++) printf("%d ", a[i]);
        printf("\n");
    }
    return 0;
}

L7–L8 · Singly and doubly linked lists

Linked lists

  • Node: struct node { int data; struct node *next; };, allocated with malloc(sizeof(struct node)). Include <stdlib.h>.
  • Every insert and delete has a special case: the empty list, and changing the head. Draw the boxes and arrows before writing pointer code.
  • To delete in an SLL you need the node before it, so walk with two pointers prev and p. A DLL node already knows its prev.
  • Order matters when relinking: set the new node's pointers first, then change the existing nodes. Doing it the other way loses the rest of the list.

Try these first

  1. Insert at front, end and a given position; delete by value; search; display.
  2. Reverse the list without recursion using O(1) extra space. Hint: three pointers prev, cur, next.
  3. DLL: insert at both ends, delete a given value, print forwards and backwards.
  4. Not solved here, but same pattern: find the middle node in one pass (slow and fast pointers); detect a loop; merge two sorted lists; circular SLL insert and delete (CLRS 10.2-5).
Singly linked list with reverse CLRS 10.2, 10.2-7
sll.c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};
struct node *head = NULL;

struct node *newNode(int x) {
    struct node *t = (struct node *)malloc(sizeof(struct node));
    t->data = x;
    t->next = NULL;
    return t;
}

void insertFront(int x) {
    struct node *t = newNode(x);
    t->next = head;
    head = t;
}

void insertEnd(int x) {
    struct node *t = newNode(x), *p = head;
    if (head == NULL) { head = t; return; }
    while (p->next != NULL) p = p->next;
    p->next = t;
}

/* position 1 = front */
void insertAt(int x, int pos) {
    struct node *t, *p = head;
    int i;
    if (pos == 1) { insertFront(x); return; }
    for (i = 1; i < pos - 1 && p != NULL; i++) p = p->next;
    if (p == NULL) { printf("Invalid position\n"); return; }
    t = newNode(x);
    t->next = p->next;
    p->next = t;
}

void deleteKey(int x) {
    struct node *p = head, *prev = NULL;
    while (p != NULL && p->data != x) { prev = p; p = p->next; }
    if (p == NULL) { printf("%d not found\n", x); return; }
    if (prev == NULL) head = p->next;      /* deleting the first node */
    else prev->next = p->next;
    free(p);
    printf("Deleted %d\n", x);
}

int search(int x) {
    struct node *p = head;
    int pos = 1;
    while (p != NULL) {
        if (p->data == x) return pos;
        p = p->next; pos++;
    }
    return -1;
}

/* CLRS 10.2-7: non-recursive, O(n) time, O(1) extra space */
void reverse(void) {
    struct node *prev = NULL, *cur = head, *nxt;
    while (cur != NULL) {
        nxt = cur->next;
        cur->next = prev;
        prev = cur;
        cur = nxt;
    }
    head = prev;
}

void display(void) {
    struct node *p = head;
    if (p == NULL) { printf("List empty\n"); return; }
    while (p != NULL) { printf("%d -> ", p->data); p = p->next; }
    printf("NULL\n");
}

int main(void) {
    int ch, x, pos;
    while (1) {
        printf("1.InsFront 2.InsEnd 3.InsAt 4.Delete 5.Search 6.Reverse 7.Display 8.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); insertFront(x); break;
        case 2: scanf("%d", &x); insertEnd(x); break;
        case 3: scanf("%d %d", &x, &pos); insertAt(x, pos); break;
        case 4: scanf("%d", &x); deleteKey(x); break;
        case 5: scanf("%d", &x); pos = search(x);
                if (pos == -1) printf("%d not found\n", x); else printf("%d found at position %d\n", x, pos);
                break;
        case 6: reverse(); printf("Reversed\n"); break;
        case 7: display(); break;
        case 8: return 0;
        }
    }
    return 0;
}

Doubly linked list CLRS 10.2

Keeping a tail pointer makes insert-at-end O(1) and lets you print backwards. On delete, fix the neighbour on each side, or move head/tail if there is no neighbour.

dll.c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *prev, *next;
};
struct node *head = NULL, *tail = NULL;

struct node *newNode(int x) {
    struct node *t = (struct node *)malloc(sizeof(struct node));
    t->data = x;
    t->prev = t->next = NULL;
    return t;
}

void insertFront(int x) {
    struct node *t = newNode(x);
    if (head == NULL) { head = tail = t; return; }
    t->next = head;
    head->prev = t;
    head = t;
}

void insertEnd(int x) {
    struct node *t = newNode(x);
    if (tail == NULL) { head = tail = t; return; }
    t->prev = tail;
    tail->next = t;
    tail = t;
}

void deleteKey(int x) {
    struct node *p = head;
    while (p != NULL && p->data != x) p = p->next;
    if (p == NULL) { printf("%d not found\n", x); return; }
    if (p->prev != NULL) p->prev->next = p->next; else head = p->next;
    if (p->next != NULL) p->next->prev = p->prev; else tail = p->prev;
    free(p);
    printf("Deleted %d\n", x);
}

void displayForward(void) {
    struct node *p = head;
    printf("Forward:  NULL <-> ");
    while (p != NULL) { printf("%d <-> ", p->data); p = p->next; }
    printf("NULL\n");
}

void displayBackward(void) {
    struct node *p = tail;
    printf("Backward: NULL <-> ");
    while (p != NULL) { printf("%d <-> ", p->data); p = p->prev; }
    printf("NULL\n");
}

int main(void) {
    int ch, x;
    while (1) {
        printf("1.InsFront 2.InsEnd 3.Delete 4.Forward 5.Backward 6.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); insertFront(x); break;
        case 2: scanf("%d", &x); insertEnd(x); break;
        case 3: scanf("%d", &x); deleteKey(x); break;
        case 4: displayForward(); break;
        case 5: displayBackward(); break;
        case 6: return 0;
        }
    }
    return 0;
}

Viva quick-fire

Array vs linked list: when is each better?

Arrays give O(1) access by index and better cache use. Linked lists give O(1) insert and delete once you have the node, and grow without a fixed size.

Cost of deleting a given node in an SLL vs a DLL?

SLL: O(n), because you must find the previous node. DLL: O(1), because the node has a prev pointer.

What is a sentinel node (CLRS L.nil)?

A dummy node that sits between head and tail of a circular DLL, so insert and delete never need the empty-list or end-of-list special cases.

L9–L12 · Stacks, queues, circular queues

Stacks and queues

  • Stack is LIFO: push and pop at the same end. Queue is FIFO: enqueue at the rear, dequeue at the front.
  • A linear array queue wastes the slots in front of front. A circular queue wraps with % N.
  • Circular queue: empty when front == -1, full when (rear + 1) % N == front. Moving backwards use (i − 1 + N) % N so it never goes negative.
  • Check underflow before you pop or dequeue, in main or inside the function, every time.

  4. Stack using two queues. Which operation is expensive?

Deque in a circular array CLRS 10.1-5
deque.c
#include <stdio.h>
#define N 5

/* CLRS 10.1-5: deque in a circular array, all four operations O(1) */
int dq[N], front = -1, rear = -1;

int isFull(void)  { return (rear + 1) % N == front; }
int isEmpty(void) { return front == -1; }

void insertFront(int x) {
    if (isFull()) { printf("Deque overflow\n"); return; }
    if (isEmpty()) front = rear = 0;
    else front = (front - 1 + N) % N;     /* +N keeps it non-negative */
    dq[front] = x;
}

void insertRear(int x) {
    if (isFull()) { printf("Deque overflow\n"); return; }
    if (isEmpty()) front = rear = 0;
    else rear = (rear + 1) % N;
    dq[rear] = x;
}

int deleteFront(void) {
    int x = dq[front];
    if (front == rear) front = rear = -1;
    else front = (front + 1) % N;
    return x;
}

int deleteRear(void) {
    int x = dq[rear];
    if (front == rear) front = rear = -1;
    else rear = (rear - 1 + N) % N;
    return x;
}

void display(void) {
    int i;
    if (isEmpty()) { printf("Deque empty\n"); return; }
    for (i = front; ; i = (i + 1) % N) { printf("%d ", dq[i]); if (i == rear) break; }
    printf("\n");
}

int main(void) {
    int ch, x;
    while (1) {
        printf("1.InsFront 2.InsRear 3.DelFront 4.DelRear 5.Display 6.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); insertFront(x); break;
        case 2: scanf("%d", &x); insertRear(x); break;
        case 3: if (isEmpty()) printf("Deque underflow\n"); else printf("Deleted %d\n", deleteFront()); break;
        case 4: if (isEmpty()) printf("Deque underflow\n"); else printf("Deleted %d\n", deleteRear()); break;
        case 5: display(); break;
        case 6: return 0;
        }
    }
    return 0;
}

Queue using two stacks CLRS 10.1-6

Push new elements onto s1. To dequeue, pop from s2; if s2 is empty, first pour all of s1 into s2, which reverses their order so the oldest is on top. Each element moves at most once, so dequeue is O(1) amortised and O(n) worst case.

queue_two_stacks.c
#include <stdio.h>
#define N 50

/* CLRS 10.1-6: queue using two stacks.
   s1 receives new elements; s2 holds elements in dequeue order.
   Enqueue O(1); dequeue O(n) worst case, O(1) amortised. */
int s1[N], s2[N], top1 = -1, top2 = -1;

void enqueue(int x) {
    if (top1 == N - 1) { printf("Queue overflow\n"); return; }
    s1[++top1] = x;
}

int dequeue(void) {
    if (top2 == -1)                       /* refill s2 only when it is empty */
        while (top1 != -1) s2[++top2] = s1[top1--];
    return s2[top2--];
}

int main(void) {
    int ch, x;
    while (1) {
        printf("1.Enqueue 2.Dequeue 3.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); enqueue(x); break;
        case 2: if (top1 == -1 && top2 == -1) printf("Queue underflow\n");
                else printf("Dequeued %d\n", dequeue());
                break;
        case 3: return 0;
        }
    }
    return 0;
}

Stack using two queues CLRS 10.1-7

Push enqueues into q1 in O(1). To pop, move all but the last element of q1 into q2; the last one is the top of the stack. Then q2 becomes the main queue. Pop is O(n).

stack_two_queues.c
#include <stdio.h>
#define N 50

/* CLRS 10.1-7: stack using two queues.
   Push O(1). Pop O(n): move all but the last element of q1 to q2,
   remove the last one, then swap the roles of q1 and q2. */
int q1[N], q2[N], f1 = 0, r1 = 0, f2 = 0, r2 = 0;   /* simple linear queues: [f, r) */

void push(int x) {
    if (r1 == N) { printf("Stack overflow\n"); return; }
    q1[r1++] = x;
}

int pop(void) {
    int x, i;
    while (r1 - f1 > 1) q2[r2++] = q1[f1++];   /* move n-1 elements */
    x = q1[f1++];                               /* last one = top of stack */
    for (i = 0; i < r2 - f2; i++) q1[i] = q2[f2 + i];   /* q2 becomes q1 */
    r1 = r2 - f2; f1 = 0;
    f2 = r2 = 0;
    return x;
}

int main(void) {
    int ch, x;
    while (1) {
        printf("1.Push 2.Pop 3.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); push(x); break;
        case 2: if (r1 == f1) printf("Stack underflow\n"); else printf("Popped %d\n", pop()); break;
        case 3: return 0;
        }
    }
    return 0;
}

Stack and queue using a linked list CLRS 10.2-2, 10.2-3

The stack pushes and pops at the head. The queue keeps a rear pointer so enqueue is O(1); when the last node leaves, set rear back to NULL too.

ll_stack_queue.c
#include <stdio.h>
#include <stdlib.h>

struct node { int data; struct node *next; };

/* ---- Stack: push and pop both at the head -> O(1) (CLRS 10.2-2) ---- */
struct node *top = NULL;

void push(int x) {
    struct node *t = (struct node *)malloc(sizeof(struct node));
    t->data = x;
    t->next = top;
    top = t;
}

int pop(void) {
    struct node *t = top;
    int x = t->data;
    top = top->next;
    free(t);
    return x;
}

/* ---- Queue: enqueue at rear, dequeue at front -> O(1) (CLRS 10.2-3) ---- */
struct node *front = NULL, *rear = NULL;

void enqueue(int x) {
    struct node *t = (struct node *)malloc(sizeof(struct node));
    t->data = x;
    t->next = NULL;
    if (rear == NULL) front = rear = t;
    else { rear->next = t; rear = t; }
}

int dequeue(void) {
    struct node *t = front;
    int x = t->data;
    front = front->next;
    if (front == NULL) rear = NULL;   /* queue became empty */
    free(t);
    return x;
}

int main(void) {
    int ch, x;
    while (1) {
        printf("1.Push 2.Pop 3.Enqueue 4.Dequeue 5.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); push(x); printf("Pushed %d\n", x); break;
        case 2: if (top == NULL) printf("Stack underflow\n"); else printf("Popped %d\n", pop()); break;
        case 3: scanf("%d", &x); enqueue(x); printf("Enqueued %d\n", x); break;
        case 4: if (front == NULL) printf("Queue underflow\n"); else printf("Dequeued %d\n", dequeue()); break;
        case 5: return 0;
        }
    }
    return 0;
}

L11, L14 · Priority queues and heaps

Heap operations

  • Two moves do all the work: sift down (MAX-HEAPIFY) when a value may be too small for its spot, sift up (HEAP-INCREASE-KEY) when it may be too big.
  • Insert = add at the end + sift up. Extract = move last element to the root + sift down. Both O(lg n).
  • CLRS uses 1-based arrays: parent i/2, children 2i and 2i+1. This program follows CLRS.

Try these first

  1. Max priority queue: insert, extract max, increase key, display.
  2. Min priority queue version: extract min, decrease key (CLRS 6.5-3). Flip every comparison.
  3. Delete the element at index i in O(lg n) (CLRS 6.5-8). Hint: the value you move in may need to go up or down.
  4. Not solved here: implement a stack and a FIFO queue using a priority queue (6.5-7, give each element a counter as its key); merge k sorted lists with a min heap (6.5-9).
Max heap: insert, extract max, increase key, delete at index CLRS 6.5, 6.5-8
heap_ops.c
#include <stdio.h>
#define MAX 50

/* Max heap, 1-based like CLRS ch.6. For a min heap flip every comparison (CLRS 6.5-3). */
int A[MAX + 1], n = 0;

void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }

void maxHeapify(int i) {                 /* sift down, CLRS MAX-HEAPIFY */
    int l = 2 * i, r = 2 * i + 1, largest = i;
    if (l <= n && A[l] > A[largest]) largest = l;
    if (r <= n && A[r] > A[largest]) largest = r;
    if (largest != i) { swap(&A[i], &A[largest]); maxHeapify(largest); }
}

void increaseKey(int i, int key) {       /* sift up, CLRS HEAP-INCREASE-KEY */
    if (key < A[i]) { printf("New key is smaller than current key\n"); return; }
    A[i] = key;
    while (i > 1 && A[i / 2] < A[i]) { swap(&A[i], &A[i / 2]); i = i / 2; }
}

void insert(int key) {                   /* CLRS MAX-HEAP-INSERT */
    if (n == MAX) { printf("Heap overflow\n"); return; }
    n++;
    A[n] = -32768;                       /* "minus infinity", then raise it */
    increaseKey(n, key);
}

int extractMax(void) {                   /* CLRS HEAP-EXTRACT-MAX */
    int max = A[1];
    A[1] = A[n--];
    maxHeapify(1);
    return max;
}

void deleteAt(int i) {                   /* CLRS 6.5-8: O(lg n) */
    int old = A[i];
    A[i] = A[n--];
    if (i > n) return;                   /* deleted the last element */
    if (A[i] > old) {                    /* moved-in value is bigger: sift up */
        while (i > 1 && A[i / 2] < A[i]) { swap(&A[i], &A[i / 2]); i = i / 2; }
    } else maxHeapify(i);                /* otherwise sift down */
}

void display(void) {
    int i;
    for (i = 1; i <= n; i++) printf("%d ", A[i]);
    printf("\n");
}

int main(void) {
    int ch, x, i;
    while (1) {
        printf("1.Insert 2.ExtractMax 3.IncreaseKey 4.DeleteAt 5.Display 6.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); insert(x); break;
        case 2: if (n < 1) printf("Heap underflow\n"); else printf("Max %d removed\n", extractMax()); break;
        case 3: scanf("%d %d", &i, &x);
                if (i < 1 || i > n) printf("Invalid index\n"); else increaseKey(i, x);
                break;
        case 4: scanf("%d", &i);
                if (i < 1 || i > n) printf("Invalid index\n"); else deleteAt(i);
                break;
        case 5: display(); break;
        case 6: return 0;
        }
    }
    return 0;
}

  • Lomuto PARTITION: i marks the end of the "≤ pivot" region. Each a[j] <= x grows that region by one swap. Finally put the pivot at i+1.

Quick sort and randomized quick sort CLRS 7.1, 7.3
quick.c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int comparisons = 0;

void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }

/* CLRS PARTITION (Lomuto): pivot = last element */
int partition(int a[], int p, int r) {
    int x = a[r], i = p - 1, j;
    for (j = p; j < r; j++) {
        comparisons++;
        if (a[j] <= x) {          /* use >= here for descending order (CLRS 7.1-4) */
            i++;
            swap(&a[i], &a[j]);
        }
    }
    swap(&a[i + 1], &a[r]);
    return i + 1;
}

/* CLRS RANDOMIZED-PARTITION: random pivot swapped to the end */
int randomizedPartition(int a[], int p, int r) {
    int i = p + rand() % (r - p + 1);
    swap(&a[i], &a[r]);
    return partition(a, p, r);
}

void quickSort(int a[], int p, int r, int randomized) {
    int q;
    if (p < r) {
        q = randomized ? randomizedPartition(a, p, r) : partition(a, p, r);
        quickSort(a, p, q - 1, randomized);
        quickSort(a, q + 1, r, randomized);
    }
}

int main(void) {
    int a[100], n, i, mode;
    srand(time(NULL));
    printf("n: "); scanf("%d", &n);
    printf("Elements: ");
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    printf("1.Normal 2.Randomized: "); scanf("%d", &mode);
    quickSort(a, 0, n - 1, mode == 2);
    printf("\nSorted: ");
    for (i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\nComparisons: %d\n", comparisons);
    return 0;
}

Merge sort without sentinels, with inversion count CLRS 2.3-2, 2-4

An inversion is a pair i < j with a[i] > a[j]. When MERGE takes R[j] before the remaining L[i..n1−1], every one of those L elements forms an inversion with R[j], so add n1 − i.

merge.c
#include <stdio.h>

long inversions = 0;

/* CLRS 2.3-2: MERGE without sentinels. a[p..q] and a[q+1..r] are sorted. */
void merge(int a[], int p, int q, int r) {
    int n1 = q - p + 1, n2 = r - q, i, j, k;
    int L[100], R[100];
    for (i = 0; i < n1; i++) L[i] = a[p + i];
    for (j = 0; j < n2; j++) R[j] = a[q + 1 + j];
    i = j = 0; k = p;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) a[k++] = L[i++];
        else {
            a[k++] = R[j++];
            inversions += n1 - i;     /* CLRS problem 2-4: every remaining L[] > R[j] */
        }
    }
    while (i < n1) a[k++] = L[i++];   /* copy whichever side is left over */
    while (j < n2) a[k++] = R[j++];
}

void mergeSort(int a[], int p, int r) {
    int q;
    if (p < r) {
        q = (p + r) / 2;
        mergeSort(a, p, q);
        mergeSort(a, q + 1, r);
        merge(a, p, q, r);
    }
}

int main(void) {
    int a[100], n, i;
    printf("n: "); scanf("%d", &n);
    printf("Elements: ");
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    mergeSort(a, 0, n - 1);
    printf("\nSorted: ");
    for (i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\nInversions in input: %ld\n", inversions);
    return 0;
}

Viva quick-fire

What does PARTITION return when all elements are equal (CLRS 7.1-2)?

r, the last index, because every element satisfies a[j] <= x. That makes every split n−1 and 0, so equal elements give Θ(n²).

Why is merge sort preferred for linked lists?

It needs only sequential access, and merging lists needs no extra array. Quick sort and heap sort rely on random access.

Which sort would you use in a memory-limited embedded system?

Heap sort: guaranteed O(n lg n) and O(1) extra memory, with no deep recursion.

L16–L18 · Binary, linear, Fibonacci search

Searching

  • Linear search works on any array, Θ(n). Binary and Fibonacci search need a sorted array, Θ(lg n).
  • Binary search loop condition is low <= high, not <. Compute mid = low + (high − low) / 2 to avoid integer overflow.
  • Fibonacci search splits at Fibonacci-number offsets instead of the middle. It uses only addition and subtraction, which once mattered on hardware without fast division.

  2. Fibonacci search on the same array.
  3. Count the comparisons each method makes for a key that is absent.
  4. Not solved here: find the first occurrence of a repeated key with binary search; find the insertion position of a key.
Linear, binary (iterative and recursive) and Fibonacci search CLRS 2.1-3, 2.3-5
search.c
#include <stdio.h>

int linearSearch(int a[], int n, int key) {           /* CLRS 2.1-3 */
    int i;
    for (i = 0; i < n; i++) if (a[i] == key) return i;
    return -1;
}

int binaryIter(int a[], int n, int key) {             /* CLRS 2.3-5, needs sorted a[] */
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = low + (high - low) / 2;                 /* avoids overflow of low+high */
        if (a[mid] == key) return mid;
        else if (a[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}

int binaryRec(int a[], int low, int high, int key) {
    int mid;
    if (low > high) return -1;
    mid = low + (high - low) / 2;
    if (a[mid] == key) return mid;
    if (a[mid] < key) return binaryRec(a, mid + 1, high, key);
    return binaryRec(a, low, mid - 1, key);
}

int min(int x, int y) { return x < y ? x : y; }

/* Fibonacci search: split points come from Fibonacci numbers instead of halves */
int fibonacciSearch(int a[], int n, int key) {
    int fm2 = 0, fm1 = 1, fm = fm2 + fm1, offset = -1, i;
    while (fm < n) { fm2 = fm1; fm1 = fm; fm = fm2 + fm1; }   /* smallest Fib >= n */
    while (fm > 1) {
        i = min(offset + fm2, n - 1);
        if (a[i] < key) { fm = fm1; fm1 = fm2; fm2 = fm - fm1; offset = i; }       /* go right */
        else if (a[i] > key) { fm = fm2; fm1 = fm1 - fm2; fm2 = fm - fm1; }        /* go left */
        else return i;
    }
    if (fm1 && offset + 1 < n && a[offset + 1] == key) return offset + 1;
    return -1;
}

int main(void) {
    int a[100], n, i, key, ch, pos = -1;
    printf("n: "); scanf("%d", &n);
    printf("Elements (sorted for binary/Fibonacci): ");
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    printf("Key: "); scanf("%d", &key);
    printf("1.Linear 2.Binary iterative 3.Binary recursive 4.Fibonacci: "); scanf("%d", &ch);
    switch (ch) {
    case 1: pos = linearSearch(a, n, key); break;
    case 2: pos = binaryIter(a, n, key); break;
    case 3: pos = binaryRec(a, 0, n - 1, key); break;
    case 4: pos = fibonacciSearch(a, n, key); break;
    }
    if (pos == -1) printf("\n%d not found\n", key);
    else printf("\n%d found at index %d\n", key, pos);
    return 0;
}

L19–L23 · Tree terminology, binary trees, BSTs, balanced trees

Trees

  • BST property: everything in the left subtree is smaller than the node, everything in the right subtree is larger. Inorder traversal therefore prints keys in sorted order.
  • Delete has three cases: leaf (remove it), one child (link the child up), two children (copy the inorder successor's key, then delete the successor from the right subtree).
  • Successor: if there is a right subtree, its minimum. Otherwise the nearest ancestor for which the node is in the left subtree.
  • Height: this page counts edges, so a single node has height 0 and an empty tree −1. State your convention in the write-up.
  • Balanced trees (AVL) keep every node's balance factor in {−1, 0, 1} using LL, RR, LR and RL rotations, so height stays O(lg n). A full AVL program is unlikely in a 15-minute lab, but expect viva questions.

Binary search tree: all operations and traversals CLRS 10.4, 12.1–12.3

The test uses the keys of CLRS Figure 12.2. The successor and predecessor functions walk down from the root, so the nodes need no parent pointer.

bst.c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int key;
    struct node *left, *right;
};

struct node *newNode(int k) {
    struct node *t = (struct node *)malloc(sizeof(struct node));
    t->key = k;
    t->left = t->right = NULL;
    return t;
}

struct node *insert(struct node *root, int k) {        /* recursive, CLRS 12.3-1 */
    if (root == NULL) return newNode(k);
    if (k < root->key) root->left = insert(root->left, k);
    else if (k > root->key) root->right = insert(root->right, k);
    return root;                                         /* duplicates ignored */
}

struct node *search(struct node *root, int k) {
    while (root != NULL && root->key != k)
        root = (k < root->key) ? root->left : root->right;
    return root;
}

struct node *minNode(struct node *t) { while (t->left != NULL) t = t->left; return t; }
struct node *maxNode(struct node *t) { while (t->right != NULL) t = t->right; return t; }

struct node *delete(struct node *root, int k) {
    struct node *t;
    if (root == NULL) { printf("%d not found\n", k); return NULL; }
    if (k < root->key) root->left = delete(root->left, k);
    else if (k > root->key) root->right = delete(root->right, k);
    else {
        if (root->left == NULL) { t = root->right; free(root); return t; }    /* 0 or 1 child */
        if (root->right == NULL) { t = root->left; free(root); return t; }
        t = minNode(root->right);               /* 2 children: copy inorder successor */
        root->key = t->key;
        root->right = delete(root->right, t->key);
    }
    return root;
}

/* successor without parent pointers: walk down from the root */
struct node *successor(struct node *root, int k) {
    struct node *x = search(root, k), *succ = NULL;
    if (x == NULL) return NULL;
    if (x->right != NULL) return minNode(x->right);
    while (root != x) {
        if (k < root->key) { succ = root; root = root->left; }  /* last left turn */
        else root = root->right;
    }
    return succ;
}

struct node *predecessor(struct node *root, int k) {    /* CLRS 12.2-3 */
    struct node *x = search(root, k), *pred = NULL;
    if (x == NULL) return NULL;
    if (x->left != NULL) return maxNode(x->left);
    while (root != x) {
        if (k > root->key) { pred = root; root = root->right; }  /* last right turn */
        else root = root->left;
    }
    return pred;
}

void inorder(struct node *t)   { if (t) { inorder(t->left); printf("%d ", t->key); inorder(t->right); } }
void preorder(struct node *t)  { if (t) { printf("%d ", t->key); preorder(t->left); preorder(t->right); } }
void postorder(struct node *t) { if (t) { postorder(t->left); postorder(t->right); printf("%d ", t->key); } }

/* CLRS 10.4-3 / 12.1-3: inorder without recursion, using an explicit stack */
void inorderIter(struct node *root) {
    struct node *stack[100], *cur = root;
    int top = -1;
    while (cur != NULL || top != -1) {
        while (cur != NULL) { stack[++top] = cur; cur = cur->left; }   /* go left as far as possible */
        cur = stack[top--];
        printf("%d ", cur->key);
        cur = cur->right;
    }
}

int height(struct node *t) {          /* edges on longest root-leaf path; empty tree = -1 */
    int hl, hr;
    if (t == NULL) return -1;
    hl = height(t->left); hr = height(t->right);
    return 1 + (hl > hr ? hl : hr);
}

int countNodes(struct node *t)  { return t ? 1 + countNodes(t->left) + countNodes(t->right) : 0; }
int countLeaves(struct node *t) {
    if (t == NULL) return 0;
    if (t->left == NULL && t->right == NULL) return 1;
    return countLeaves(t->left) + countLeaves(t->right);
}

int main(void) {
    struct node *root = NULL, *r;
    int ch, x;
    while (1) {
        printf("1.Insert 2.Delete 3.Search 4.Traversals 5.Min/Max 6.Succ/Pred 7.Height/Count 8.Exit: ");
        if (scanf("%d", &ch) != 1) break;
        switch (ch) {
        case 1: scanf("%d", &x); root = insert(root, x); break;
        case 2: scanf("%d", &x); root = delete(root, x); break;
        case 3: scanf("%d", &x); printf("%d %s\n", x, search(root, x) ? "found" : "not found"); break;
        case 4: if (!root) { printf("Tree empty\n"); break; }
                printf("Inorder:   "); inorder(root);
                printf("\nPreorder:  "); preorder(root);
                printf("\nPostorder: "); postorder(root);
                printf("\nInorder (iterative): "); inorderIter(root); printf("\n");
                break;
        case 5: if (!root) printf("Tree empty\n");
                else printf("Min %d, Max %d\n", minNode(root)->key, maxNode(root)->key);
                break;
        case 6: scanf("%d", &x);
                r = successor(root, x);   printf("Successor of %d: ", x);   if (r) printf("%d\n", r->key); else printf("none\n");
                r = predecessor(root, x); printf("Predecessor of %d: ", x); if (r) printf("%d\n", r->key); else printf("none\n");
                break;
        case 7: printf("Height %d, nodes %d, leaves %d\n", height(root), countNodes(root), countLeaves(root)); break;
        case 8: return 0;
        }
    }
    return 0;
}

Worst-case height of a BST with n nodes, and when does it happen?

n − 1, when keys are inserted in sorted order and the tree degenerates into a list. Search then costs O(n). This is why balanced trees exist.

A BST, by inorder traversal. A heap only orders parent against child, so producing sorted output needs heap sort, O(n lg n).
