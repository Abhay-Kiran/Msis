1. Scope & notes

All page numbers are the printed book page numbers, not PDF page numbers.

Not well covered in the textbook — use another source:
  • ARM architecture & components (L2), SoC, VLIW (L1): Furber, ARM System-on-Chip Architecture (ref. 10) or Sloss et al., ARM System Developer's Guide (ref. 12).
  • Data hazards, instruction hazards, influence on instruction sets, datapath & control considerations (L30–L31): these titles match the pipelining chapter of Hamacher et al., Computer Organization 5th ed. (ref. 1), which as far as I know is Chapter 8. Rafiquzzaman only covers branch hazards and memory conflicts.

5. Practice question papers

50 marks each (5 × 10) · 90 minutes · Q1–3 theory & design, Q4–5 application/numerical

Paper A

  1. (a) Compare Von Neumann and Harvard architectures with block diagrams. (b) Evaluate D := A + B*C with three-, two-, one- and zero-address instructions. [Fig 1.1, Q1.2, pp. 12–15]CO1
  2. Derive the carry look-ahead equations C1–C4. Design a 16-bit adder using 4-bit CLA blocks and show its worst-case delay is 12Δ, compared with 33Δ for a ripple-carry adder. [pp. 75–78]CO1
  3. Classify computers using Flynn's scheme with one example each. Explain the organization of an SIMD array processor, including the role of the mask register. [pp. 306–309, Q7.8]CO3
  4. Multiply 110011 × 110110 (−13 × −10) using Booth's algorithm, showing the A, Q and q−1 trace. [Q3.26a]CO1
  5. A 4-segment floating-point add pipeline has T1 = 40, T2 = 100, T3 = 180, T4 = 60 ns and latch delay 20 ns. Find (a) the clock period, (b) the time to add 1000 pairs, (c) the efficiency for 2000 pairs. [Q7.12]CO3

Paper B

  1. With a neat diagram, design a 4-bit general-purpose register using the basic cell S. Show how logical, arithmetic and rotate right shifts are obtained through input R. [pp. 63–66]CO1
  2. Design a 16×16 barrel shifter as a two-level shifter and explain the rotation by 11 positions. [pp. 68–71, Q3.4]CO1
  3. List the ways parallelism is achieved in a uniprocessor system. Compare single-bus and crossbar interconnections for multiprocessors. [p. 305, pp. 328–331, Q7.19]CO3
  4. An instruction is 11 bits long with 4-bit address fields. Is it possible to have (i) 5 two-address, 45 one-address and 32 zero-address instructions; (ii) 7, 15 and 18? Justify using the expanding opcode technique. [Q2.4, Q2.5]CO1
  5. 1000 instructions run on a 6-segment pipeline. (a) Find the average instructions per instruction cycle when c = 0.2. (b) What value of c allows at least 4 instructions per cycle? (c) Explain target prefetch and delayed branch. [Q7.14, Q7.15, pp. 322–325]CO3

Paper C

  1. Design a 4-bit, four-function ALU (add, subtract, AND, XOR) using a parallel adder and multiplexers, and give its function table. [pp. 84–88, Figs 3.22–3.26]CO1
  2. Explain the carry-save adder and the Wallace tree. Show how an 8×8 multiplier is built from 4×4 multipliers and a Wallace tree. [pp. 80–83, 98–100]CO1
  3. Explain pipelining with a space-time diagram and derive expressions for speedup, throughput and efficiency. Explain how memory interleaving reduces memory-access conflicts. [pp. 315–317, 325–326, Q7.17]CO3
  4. (a) Multiply 10101 × 11001 using the add-shift method, showing the F, A, Q trace. [Q3.25] (b) For A = 01100010 and B = 01000101, find the N, Z, V and C flags for A + B. [Example 3.1]CO1
  5. (a) A processor array has 4 floating-point processors, each taking 4 time units per result. Compare the time for 100 operations with a 4-segment pipeline of 1 time unit per segment. [Q7.7] (b) Rewrite the program in Fig 7.20 for a 2-segment pipeline using delayed branch, first with a NOP and then by reordering. [pp. 323–325, Q7.16]CO3
